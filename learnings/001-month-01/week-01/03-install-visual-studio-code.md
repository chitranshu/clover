# Install Visual Studio Code

## Step 1: Download and Install Visual Studio Code
- Go to the official Visual Studio Code website: https://code.visualstudio.com
- Click on the "Download" button for your operating system (Windows, macOS, or Linux).
- Run the installer and follow the prompts to complete the installation.

## Step 2: Install Python Extension
- Open Visual Studio Code.
- Click on the Extensions icon in the left sidebar (or press `Ctrl+Shift+X` on Windows/Linux, `Cmd+Shift+X` on Mac).
- Search for "Python" in the Extensions marketplace.
- Click on the "Python" extension by Microsoft and click "Install".

## Step 3: Configure Python Interpreter
- Open a Python file or create a new one (e.g., `hello.py`).
- Click on the Python version displayed in the bottom-right corner of the VS Code window.
- Select the Python interpreter you want to use (e.g., the one from your virtual environment if you set one up).

## Step 4: Verify Python Extension Functionality
- Create a simple Python script (e.g., `hello.py`) with the following content:
```python
print("Hello, Visual Studio Code!")
```
- Save the file and run it by right-clicking in the editor and selecting "Run Python File in Terminal".
- You should see the output "Hello, Visual Studio Code!" in the terminal

## Step 5: Install Jupyter Extension
- In the Extensions marketplace, search for "Jupyter".
- Click on the "Jupyter" extension by Microsoft and click "Install".
- This extension allows you to work with Jupyter notebooks directly in VS Code.
- You can create a new Jupyter notebook by clicking on the "New File" icon and selecting "Jupyter Notebook" from the dropdown menu.
- You can also open existing `.ipynb` files and work with them in VS Code

## Step 6: Explore Additional Extensions (Optional)
- You can explore and install additional extensions for features like Git integration, code formatting, linting, and more based on your needs.
- Some popular extensions include:
  - GitLens (for Git integration)
  - Prettier (for code formatting)
  - Pylint or Flake8 (for Python linting)
