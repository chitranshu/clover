# Install Jupyter Notebook

## Step 1: Install Jupyter Notebook
- Open a terminal or command prompt.
- If you have a virtual environment set up, make sure to activate it.
- Run the following command to install Jupyter Notebook:
```bash
pip install notebook
```

## Step 2: Launch Jupyter Notebook
- In the terminal, navigate to the directory where you want to create your notebooks.
- Run the following command to start Jupyter Notebook:
```bash
jupyter notebook
```
- This will open a new tab in your default web browser with the Jupyter Notebook interface.

## Step 3: Create a New Notebook
- In the Jupyter Notebook interface, click on the "New" button in the top-right corner and select "Python 3" (or the appropriate Python version) from the dropdown menu.
- This will create a new notebook where you can write and execute Python code.
- You can create cells for code, markdown, and more. To run a cell, click on it and press `Shift + Enter` or click the "Run" button in the toolbar.
- You can also save your notebook by clicking on "File" > "Save and Checkpoint" or using the keyboard shortcut `Ctrl + S` (Windows/Linux) or `Cmd + S` (Mac).
- You can organize your notebooks in folders and manage them through the Jupyter interface. To stop the Jupyter server, go back to the terminal and press `Ctrl + C`.
- Notes: Jupyter Notebooks are great for interactive coding, data analysis, and documentation. You can mix code, text, and visualizations in a single document.
- Optional: You can also install JupyterLab, which is an enhanced interface for Jupyter Notebooks, by running:
```bash
pip install jupyterlab
```
- To launch JupyterLab, run:
```bash
jupyter lab
```
- JupyterLab provides a more flexible and powerful environment for working with notebooks, code, and data.
- You can explore additional Jupyter extensions for features like code formatting, variable inspection, and more to enhance your notebook experience.
- Remember to keep your Jupyter Notebook server running in the terminal while you work with your notebooks. You can open multiple notebooks in the same server instance.
- Happy coding and exploring with Jupyter Notebooks!
